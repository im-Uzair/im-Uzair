### 👨‍💻 About Me

I am a Software & AI Engineer focused on **Agentic Workflows**, **LLM System Reliability**, and **Production Backend Infrastructure**. 

Instead of building generic wrapper tutorials, I engineer systems that bridge deterministic software tooling (static analysis, AST parsers, linters) with autonomous LLM reasoning to solve real engineering bottlenecks.

- 🔭 **Current Focus**: Engineering **[PR-Sentinel](https://github.com/im-Uzair/pr-sentinel)** — an autonomous code review & security agent for CI/CD pipelines.
- ⚡ **Core Philosophy**: Deterministic verification first, agentic reasoning second, continuous evaluation always.
- 🛠️ **Everyday Stack**: Python, FastAPI, Pydantic v2, LangGraph, LiteLLM, Gemini & Claude APIs.
- 💬 **Ask me about**: Agent tool design, mitigating LLM hallucinations, and structuring typed backend microservices.
